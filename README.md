## What I Know So Far

### Week 1: Linux Fundamentals
- File system navigation (`cd`, `ls`, `pwd`)
- File operations (`touch`, `cp`, `mv`, `rm`, `cat`)
- Directory management (`mkdir`, `rm -r`)
- File permissions (`chmod`, `ls -la`, how rwx works)
- Users and groups (`whoami`, `id`, `/etc/passwd`)
- Admin access (`sudo`, `apt`)
- Process management (`ps`, `htop`)
- Basic scripts (`#!/bin/bash`, `chmod +x`)

### Week 2: Package Management, Services & Networking
- Package management: `apt`, `apt search`, `apt show`, `dpkg -l`
- Services: `systemctl` (status, start, stop, restart, enable)
- Networking: `ip addr show`, `ip route`, `ping`, `nslookup`, `ss`
